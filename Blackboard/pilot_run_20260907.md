# Setup

- Population: 3,295 PDFs in `~/Other/Paper/Pdf` (the whole `~/Other` tree is
  ~41,400 files, 23 GB). Sample: 20, `random.Random(20260907).sample`.
- Producer: `reference/libangel_catalog.py` with the new PDF branch
  (pdftotext -layout), `--allow-doc-vector --allow-text-prefix`, default
  policy `public_library_science`, bge-small-en-v1.5 profile 1, layout 1.3.
- Machine: AK's M2 laptop, while a Gemini session was minting concurrently.
- Each file minted in a fresh subprocess (interpreter start + model load
  paid 20 times).
